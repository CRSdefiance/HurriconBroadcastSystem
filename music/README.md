# Local music library

Put audio files inside playlist subfolders here. HBS includes `hype` and `chill` as starting categories.

Supported file types: `.mp3`, `.ogg`, `.wav`, `.flac`, `.m4a`, `.aac`, and `.opus`.

For useful now-playing text, name files `Artist - Track Title.mp3`. After adding or removing music, click **Refresh folders & stations** in Setup / Preview.

Audio files are intentionally excluded from Git so licensed music is not accidentally published. Only play music you have permission to broadcast.
